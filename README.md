# MY DAILY LIFE — Android 홈 화면 위젯 (초기 개발 프로젝트)

## 현재 구현
- Android 홈 화면 위젯 (4×5칸 권장), 오늘 저장한 기록 7건 표시
- 활동·음식·건강·루틴·일기·태그 버튼을 누르면 간단한 입력 화면이 열리고 기기에 저장
- 타이머 없음; 활동 시간은 직접 입력
- 입력 후 위젯 새로고침

## 아직 미구현 (중요)
- **Netlify v7 웹앱과의 동기화**: 웹앱은 브라우저 localStorage, 이 프로젝트는 Android SharedPreferences를 사용하므로 현재 데이터가 서로 공유되지 않음
- 위젯 안에서 직접 텍스트 타이핑, 원래 기록 탭의 모든 세부 입력 필드, 사진 선택/업로드, 월간/연간 통계, 48칸 타임테이블
- 실제 APK 빌드 및 갤럭시 기기 테스트

## 빌드 방법
1. PC에 Android Studio 설치 후 이 폴더를 프로젝트로 열기
2. Gradle Sync (인터넷 필요)
3. Android 기기 연결 후 Run 실행 또는 Build > Build APK(s)
4. 갤럭시 홈 화면 길게 누르기 > 위젯 > MY DAILY LIFE 추가

## 다음 구현 단계
1. 기록 스키마를 v7 웹앱과 맞추기
2. 서버/계정 동기화 또는 안전한 양방향 데이터 교환 설계
3. 위젯 UI에서 루틴 체크·컨디션 선택 등을 바로 처리하고, 복잡한 입력만 소형 화면에서 수행
4. 사진·타임테이블·일기·건강 전체 입력 구현

참고: 프로젝트는 소스 코드이며 설치용 APK가 아닙니다. 빌드 환경이 없어 컴파일/기기 테스트는 진행하지 못했습니다.
